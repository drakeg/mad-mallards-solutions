# Agent instructions
Follow Mad Mallard Development Standards and https://github.com/drakeg/madmallard-repository-standards.
- Site uses the upstream MIT Scroll Craft engine copied intact from nateherkai/scroll-craft (pinned in vendor note below); do not modify engine per project.
- Avoid invented customer numbers, testimonials, or credentials. Preserve the minimal editorial style and accessible reduced-motion alternatives.
- Preserve real contact and subscribe form behavior; do not claim outbound email is operational.
- Run Python tests and browser walkthroughs; diagnose and fix CI.
- Protect submitted data: DB must stay gitignored, do not expose exports, and do not deploy publicly before consent, anti-abuse, and privacy review.
- README badges must remain grounded in actual manifests/CI and use dynamic status indicators.
- Keep SPRINTS.md BACKLOG.md RELEASES.md and CONTRIBUTING.md updated.
